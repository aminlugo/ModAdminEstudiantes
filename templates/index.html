Guía de Formato para Carga Masiva (CSV)
📥 Descargar CSV desde GitHub

Para cargar registros de forma masiva correctamente, su archivo .csv debe estar delimitado por punto y coma (;) y contener las siguientes columnas en su primera fila (encabezados):

numeroIdentificacion * nombres * apellidos * email * genero edad carrera semestre modalidad universidad
1012345678 Juan Carlos Perez Gomez juan@ejemplo.com Masculino 25 Ingeniería de Software 3 Virtual Politécnico

* Campos obligatorios. Los registros con números de identificación duplicados que ya existan en la base de datos se omitirán automáticamente para evitar sobreescrituras no deseadas.
